# 💎 Luxe Jewelry - Modern Jewelry E-Commerce Website

Luxe Jewelry is a modern and fully responsive e-commerce platform designed for showcasing and selling premium jewelry collections. The website provides a seamless shopping experience with an elegant user interface, secure authentication, product management, and shopping cart functionality.

## 🚀 Features

### User Features
- Browse premium jewelry collections
- Responsive design for all devices
- Product search and filtering
- Product details page
- Add to Cart functionality
- Update cart quantity
- Remove items from cart
- User Registration & Login
- Secure Authentication using JWT
- User Profile Management
- Wishlist Management
- Smooth and modern UI/UX

### Admin Features
- Manage Products
- Add New Products
- Update Product Information
- Delete Products
- Manage Users
- Manage Orders
- Dashboard Overview

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- Tailwind CSS
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB
